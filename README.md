# Bac-à-SQL 🧪

> **Bilingual (French / English) Interactive SQL Sandbox & Learning Playground**

Bac-à-SQL is an interactive web platform built to help SQL beginners, college students, and self-learners write, test, and visualize SQL CRUD queries in real time without the friction of local database installation.

---

## 🌟 Key Features (In Development)

- **Guided Levels:** Progressive interactive challenges covering basic to intermediate SQL (`SELECT`, `WHERE`, `JOIN`, `INSERT`, `UPDATE`, `DELETE`).
- **Free Sandbox Mode:** Open workspace to write arbitrary SQL commands and preview changes instantly.
- **Dynamic Visual Output:** Real-time table state rendering reflecting queries immediately.
- **Isolated User Sessions:** In-memory execution per user session to allow safe testing of destructive queries (`DROP`, `DELETE`) without corrupting shared datasets.
- **Bilingual Interface:** Fully accessible in both French and English.

---

## 🛠️ Planned Tech Stack

- **Backend:** Python (FastAPI)
- **Database Engine:** In-memory SQLite (`:memory:`)
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
